# Rationale template

- **Caller usage.** How a caller writes against this design. Written first.
- **Type sketch.** Types derived from that usage.
- **Signatures.** Functions and methods with `not implemented` bodies.
- **Module map.** Where each type and function lives.
- **What this hides.** Complexity that stays behind the public surface.
- **Rejected alternatives.** Whole-shape alternatives, not point tweaks.
- **Synthesis decision.** Filled by the parent after arena pick and graft.
