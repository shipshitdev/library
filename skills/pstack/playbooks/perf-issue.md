### Perf issue

**You own the measurement story.** Tie every fix to a measurement.

1. Capture a baseline on the matching surface.
2. Run `how` to ground hypotheses. Most fixes come from eight families.
   A family earns an attempt only when the measurement shows its signal:
   elimination, divide and conquer, caching, indirection, batching,
   redundancy, lazy evaluation, scheduling.
3. Plan the fix from the measurement. If it crosses a function boundary,
   run `architect` first. Delegate implementation to a subagent on the
   strong instruction-following tier. Capture a post-fix measurement.
4. Compare artifacts. Inconclusive or wrong-surface is not a pass.
5. Cite the measurement in the PR.
6. Run Opening a PR.

For sustained improvement against a metric, use Hillclimb.

**Reply:** baseline number, post-fix number, delta, artifact path.
