# Ship Shit Dev - Planning Bundle

Strategy, planning, and analysis skills

## Installation

```bash
/plugin marketplace add shipshitdev/skills
/plugin install shipshitdev-planning@shipshitdev
```

## Included Skills

- `roadmap-analyzer`
- `cto-advisor`
- `feature-intake`
- `task-prd-creator`
- `writing-prds`
- `prd-quality-gate`
- `rules-capture`
- `writing-plans`
