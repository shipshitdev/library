# Scoped Workflow Composition

last_verified: 2026-09-05

Skill discovery and action authorization are separate. Explicit execution routers
may invoke reusable engines only within the selected task, carrying target,
existing authorization, report-only mode, and host/provider/cost limits.
`disable-model-invocation` remains for explicit entry points and advisory workflows;
it is not a substitute for a writing engine's in-body action gates.

`ask-dev-loop`, `interview`, and `shape` retain their advisory output boundaries.
Pstack stays a public, attributed adaptation. Resolve one implementation and a
consistent set of companions from the installed catalog; resolve resources from
the selected skill directory, never an assumed consumer `skills/` checkout.

The composition validator checks explicit execution routes and relative resource
links. It distinguishes advisory references, library names, and fenced examples.
These static checks do not certify that an agent follows every instruction.
